
Практическое задание
Тема: Найти подозрительные займы с помощью моделей машинного обучения, где скорбалл >=0.6 относится к фродовым займам.
Результат работы:

1. Не менее двух видов моделей на разных алгоритмах (алгоритмы и метрики на усмотрение кандидата)
2. Описание  подхода к построению модели:
   • Какой тип модели использовали
   • Описание алгоритмов и методов, которые использовали для задачи.
3. Детализация этапов предобработки данных:
   • Как обрабатывали выбросы, пропуски, категориальные и числовые признаки.
4. План проверки качества модели:
   • Метрики оценки
   • Подходы к валидации

Формат сдачи:
Документ в текстовом формате (PDF, Word) или презентация, содержащие:
 • Перечень использованных признаков для построения моделей.
 • Обоснование выбранного подхода.
 • Описание полного процесса: обработки данных, построения моделей , проверки качества модели, и результат
